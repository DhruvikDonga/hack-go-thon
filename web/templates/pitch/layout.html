Under the Hood

Everything you need to win.

Let's dive into the extensive features baked right into the repository. When you fork hack-go-thon, you instantly get access to this powerful architectural foundation.

Real-time WebSockets

Powered by simplysocket. Built entirely in Go, routing messages to massive fleets of clients with sub-millisecond latency and O(1) complexity.

WebRTC SFU & P2P

Enterprise-grade media hub using Pion. Features a Selective Forwarding Unit for multi-party video, 1:1 signaling, and UDP DataChannels.

AI-Ready pgvector

PostgreSQL with the pgvector extension is integrated out of the box for native semantic searches and Retrieval-Augmented Generation (RAG).

RBAC & JWT Auth

Production-ready auth with bcrypt hashing, JWT validation, and multi-level Role-Based Access Control embedded directly into token claims.

Embedded Admin UI

A sleek dark-mode control center bundled into the Go binary. Live mesh visualization, RAG playground, WebRTC lab, and telemetry streams.

Dynamic API Explorer

Zero-overhead API testing playground generated via AST analysis. Dynamic path parameters, JSON formatting, and 1-click token injection.

Mobile Webhook Engine

Cryptographically signed HMAC webhooks for mobile push relays and 3rd-party consumers, backed by async Postgres delivery logs.

Multipart File Uploads

Secure file ingestion API with magic-byte MIME sniffing, SHA256 integrity checksums, and streaming download endpoints.

Jobs & Feature Flags

In-process panic-isolated task scheduler, plus services.json to selectively toggle databases, websockets, or APIs with zero code changes.

Kamal 2 Deployments

Pre-configured deploy.yml handles kamal-proxy routing, Let's Encrypt SSL, and rolling zero-downtime updates directly to your VPS.
